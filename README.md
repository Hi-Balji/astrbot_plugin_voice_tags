## 📖 简介

奶龙语音插件的完全升级版:不再只有一个写死的 mp3,而是一个**可管理的语音库**。

- 🏷️ **标签 + 使用场景说明**(和表情包插件的"分类描述"同款):每个标签可写一段给 AI 看的提示,如"嘲笑——用于幸灾乐祸、嘲讽对方时",AI 靠它判断什么时候配这条语音;
- 🤖 **自动配语音**:AI 回复末尾**自动跟一条语音**(文字和语音在同一条消息里);
- 🖥️ **独立 WebUI 管理页**(WebUI → 插件页面 → 语音库):上传、试听、改标签、编辑标签说明、删除;
- 💬 **聊天指令**快捷入库与测试。

## 📦 安装

WebUI → 插件管理 → 从插件包安装 → 选择 zip。

从旧奶龙插件迁移:把旧的 `nailong.mp3` 在语音库页面上传(或做进语音包导入),分类选 `laugh`,然后禁用旧的 astrbot_plugin_nailong_voice。

## 🖥️ WebUI 管理(WebUI → 插件页面 → 语音库)

- **分类与音频**:每个分类一行,**行内「上传音频」按钮**选完文件直接传进该分类;新建分类需先填标签名(建议英文),成功后出现在列表里再传音频;支持改说明、改名(引用它的语音自动跟着改)、删除分类(语音改为"未分类",文件保留)、**补齐推荐分类**;
- **语音列表**:试听、编辑标签、删除;
- **关键词触发规则**:配置"关键词→专属语音"。群里或私聊有人的**聊天内容里包含**关键词(单独发或夹在句子里都算,**无需@机器人、AI 不参与也会触发**;`/` 指令消息与机器人自己的消息不算)时,机器人发该规则绑定的语音——不走概率,只受冷却约束。每条规则绑一条专属语音(行内上传/更换/试听,删除规则连语音一起删);
- **发送与提示词设置**:概率/冷却/兜底开关与概率/提示词模板/恢复默认。

## 🏷️ 预置推荐分类(全新安装自动创建)

**标签键用英文**(URL/编码兼容性最好,LLM 照样看得懂),**使用场景说明用中文**(注入给 AI 判断用)。装好后在 WebUI 每个分类行点「上传音频」直接入库:

| 标签键 | 使用场景(中文,给AI看) |
|--------|------------------------|
| happy | 开心、庆祝、满分评价或期待好消息时,配欢呼或笑出声的语音 |
| laugh | 特别好笑、笑到停不下来时,配放声大笑 |
| mock | 小丑、自嘲、装酷、恶作剧、嫌弃或反讽地幸灾乐祸时 |
| comfort | 爱心、摸头、道歉、安慰对方或表达亲近陪伴时 |
| angry | 生气、责备或夸张地放狠话玩笑时;不用于真实威胁 |
| cry | 哭泣、受挫、被戳中痛处或夸张地表示自己倒下了 |
| shock | 惊吓、害怕、紧张或突然发生意外时,配短促的叫声 |
| confuse | 发呆、问号、认真思考或不知道如何接话时,配疑问语气音 |
| shy | 害羞、脸红、不好意思或撒娇卖萌的回应 |
| sleepy | 困倦、打哈欠、准备休息或吹风放松时 |
| sing | 唱歌、应援、节日或表演玩梗时,直接来一段 |
| foodie | 开饭、吃零食、馋嘴或拿食物围观聊天时 |
| money | 提到钱、红包、付款、到账、工资、中奖等金钱话题时的反应(如到账音效) |
| surprised | 惊讶、意外、目瞪口呆或完全没想到时的反应音 |
| embarrassed | 尴尬、无语、脚趾抠地或冷场时的反应音 |
| `surprised` | 惊讶、意外、目瞪口呆或完全没想到时的反应音 |
| `embarrassed` | 尴尬、无语、脚趾抠地或冷场时的反应音 |
| hello | 到达、冒泡、打招呼或发出通知时 |

共 16 个。表情包的 reply(按键摇头等动作)、work(打字摸鱼画面)两个分类是纯视觉梗,声音表现力弱,未预置;需要可自行新建。

> 从 v1.5 及以前升级的用户:旧库的中文字标签仍然有效(AI 标记匹配不受影响);点「补齐推荐分类」会补上英文键分类,乱码标签的旧音频建议删除重传。

## ❓ 常见问题

**Q: 标签还没有音频时会怎样?**
该标签**不会注入给 AI**(它根本不知道这个标签存在,自然不会选);就算 AI 从上下文里猜着写了 `%%标签%%`,也只会被静默剥掉——不发语音、不报错、不影响文字回复。所以建好标签后传上音频即自动"激活"。

**Q: 想让"AI 讲到某个词就发某条语音"?**
两种方式:① 关键词触发规则(WebUI 里配,确定性触发,适合固定梗);② 提示词里的标签说明(AI 自主判断,更灵活)。用户让 AI"笑一个""唱首歌"时,提示词已要求它选对应情绪标签的语音附上——文字回复后自动跟一段对应语音。

**Q: 想让 AI 闲聊(没命中任何标签)时也偶尔来条语音?**
启用兜底语音池:上传几条通用语音并打"兜底"标签,WebUI 设置卡里打开"兜底语音池"并调概率(比如 30%,避免每句话都跟语音);优先级最低,只在标记和关键词都没命中时生效。

## 📦 语音包导入 / 导出

WebUI 语音库页的「语音包导入 / 导出」卡:**导入**选 zip 一键入库,**导出**把当前库按同约定打 zip 下载(可直接分享或迁移,再导入全去重)。

### ✏️ 命名方法(zip 内文件怎么命名决定它导入后是什么)

| zip 内路径 | 导入结果 |
|------|------|
| `laugh/111.mp3` | **文件夹=分类**:归入 laugh 分类(不存在则自动新建,记得去补中文说明) |
| `laugh=111.mp3` | **平铺写法**:不用建文件夹,`=`前是分类、`=`后是显示名,同样归入 laugh |
| `24@man.mp3` | **关键词规则**:聊天内容包含 24 或 man 就发这条语音(多个关键词共享一条语音) |
| `@牢大.mp3` | 开头`@`=单关键词规则(只设"牢大"一个关键词) |
| `嗯.mp3`(根目录、无`=`无`@`) | 归入「未分类」中转区,永不触发,等你在语音列表里改标签(变成分类语音)或点「转触发」(变成关键词语音) |

命名规则要点:

- 分类键/关键词/显示名都可以用**中文**(Windows 资源管理器压缩的中文名会自动修复编码);分类键建议用英文,与预置分类对齐;
- 分类键与关键词不能含 `%`,长度 ≤30 字符;同包内同分类同名会去重;
- 后缀大小写随意(`.mp3`/`.MP3` 同等),支持 mp3/wav/amr/m4a/aac/ogg/silk,单条 ≤20MB,整包 ≤100MB、≤500 文件;
- 一句话同时命中多个关键词时**只发一条**(按规则列表顺序取最先命中的,防刷屏);规则组内多个关键词共享同一条语音,命中哪个结果都一样;
- 同一个关键词全局唯一:重复导入、或与已有规则撞车时跳过并报告,不会覆盖已绑定的语音;
- 自动去重按内容指纹(同分类下同内容跳过),重复导入安全。

### 🔄 与表情包插件(meme_manager)共存

标记体系独立(`%%` vs `&&`),一条回复可同时配图配语音;本插件在表情包插件之后追加语音,互不干扰。「未分类」与「兜底」标签不注入给 AI。

## ⚙️ 配置(WebUI 页面"发送与提示词设置"卡可直接调,也可用插件配置页)

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enable_inject` | bool | `true` | 向 LLM 注入语音工具提示词;关闭后仅手动 |
| `voice_probability` | int | `100` | 发送阶段配语音概率(%):LLM 写了标记后按此概率决定是否真的附语音 |
| `voice_cooldown` | int | `0` | 发送阶段冷却(秒,按会话):两次自动配语音的最小间隔,防刷屏,0=不限 |
| `fallback_enabled` | bool | `false` | 启用兜底语音池:回复没命中标记也没中关键词时,随机发一条"兜底"标签的语音 |
| `fallback_probability` | int | `100` | 兜底语音实际发送概率(%),100=只要没匹配就发 |
| `prompt_head` | string | 空=内置 | 提示词前缀(工具说明+发送格式),WebUI 可编辑 |
| `prompt_tail` | string | 空=内置 | 提示词后缀(内部资料边界+语音与上下文),WebUI 可编辑 |
| `enable_freq_hint` | bool | `true` | 附加[语音使用频率]/[语音数量偏好]提示(每约4条1条的参考节奏) |
| `enable_examples` | bool | `true` | 附加教学示例(虚构标签演示 文字+语音/纯文字/纯语音 三种形式) |

提示词体系参照 meme_manager 的成熟设计:前缀定义能力与发送格式,中间自动插入当前可用标签及用途,后缀规定内部资料边界;频率与教学示例两段可独立开关,WebUI 里一键恢复默认模板。

## 🔧 工作原理

1. 每次请求 LLM 前(`on_llm_request`),把所有**有语音的**标签及使用场景说明注入系统提示;
2. LLM 觉得回复情绪契合时,在回复末尾写 `%%标签%%`;
3. 回复出站前(`on_decorating_result`),插件剥掉标记(残缺标记也会清理,不会漏出去),从该标签随机取一条语音追加到**同一条消息**末尾——群里看到的效果就是"文字后面自己跟一段语音";
4. **关键词监听**独立于回复流程:监听收到的群/私聊消息,内容**包含**某关键词(无需 AI 参与)时,发该规则绑定的专属语音(是机器人主动发言);
5. 回复没写标记时,若启用**兜底语音池**(`fallback_enabled`),按 `fallback_probability` 概率从打了"兜底"标签的语音里随机发一条——一条 AI 回复最多附一条语音(标记 > 兜底)。关键词触发是另一条独立通道,互不影响;
6. **会话语音记忆**:机器人每发一条语音,都会把来源(哪个分类/哪条关键词触发)记入该会话的提示词(保留最近5条、30分钟)——用户问"你刚发的那语音是什么"时,AI 能说明来源;但 AI 听不到音频内容,不会编造台词。

兜底池的管理与普通语音完全一样:上传时标签填"兜底"即加入,删除或改标签即移出。

标记使用 `%%`,与表情包插件(meme_manager)的 `&&` 互相独立,两个插件可同时启用。

语音文件存于 `data/plugin_data/astrbot_plugin_voice_tags/audio/`,索引为同目录 `library.json`。
